# The Royal Invitation: Abhishek & Pavitra 💍

A stunning, ultra-premium digital wedding invitation built with React, Vite, Tailwind CSS, and Framer Motion. 

This project was completely overhauled to feature an **Obsidian Black & Liquid Gold** luxury aesthetic, delivering a jaw-dropping, cinematic experience for the guests.

## 🌐 Live Demo

You can view the live, fully interactive version of this invitation here:
**[View on Vercel](https://akshata-beauty-world.vercel.app/)**

## ✨ Premium Features

- **Liquid Gold Text & Foil Effects**: Custom CSS masking and animated gradients that mimic real shimmering gold foil on high-contrast obsidian black.
- **Cinematic Masking Reveals**: High-end Awwwards-style typography animations. Text gracefully slides up from invisible bounding boxes using ultra-smooth, custom bezier easing curves (`[0.76, 0, 0.24, 1]`).
- **Interactive 3D Glass Cards**: Moving your mouse across the screen causes the couple's photos and venue cards to dynamically tilt and shift in 3D space (`useMotionValue` & `useTransform`).
- **Global Flower Shower**: Vibrant rose and marigold petals fall elegantly from the top of the screen during the photo scenes, taking up to 30 seconds to drift gracefully down for a relaxed, romantic vibe.
- **Blooming Golden Mandalas**: Slowly rotating, intricate golden lotuses and mandalas frame the entire experience.
- **Flawless Mobile Responsiveness**: All typography, paddings, and animations dynamically scale to ensure the invitation looks just as breathtaking on an iPhone as it does on a desktop monitor.

## 🚀 Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v4 + Custom CSS Keyframes
- **Animation Engine**: Framer Motion (v12)
- **Icons**: Lucide React
- **Language**: TypeScript

## 🛠️ Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abhishekdev-ap/Weding-video-animation-website.git
   cd Weding-video-animation-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **View the site**:
   Open `http://localhost:3000` in your browser.

## 🎨 Design Philosophy

This project was designed with a "No Compromises" approach to luxury web design. We completely removed bouncy physics in favor of highly-choreographed, fluid CSS animations. The color palette (`#030303` obsidian and intricate `#d4af37` gold gradients) ensures maximum contrast and a cinematic viewing experience.
