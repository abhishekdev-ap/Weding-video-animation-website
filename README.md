# 💍 Abhishek & Pavitra — Wedding Invitation

A cinematic, animated wedding invitation web experience built with React, Framer Motion, and Tailwind CSS. Featuring a royal-themed design with immersive scene transitions, background music, and elegant typography.

## ✨ Features

- 🎬 **Cinematic Scene Transitions** — Six beautifully animated scenes: Splash → Reveal → Couple → Moments → Details → Closing
- 🎵 **Background Music** — Krishna Flute soundtrack with play/pause and volume controls
- 🌀 **Animated Mandala Patterns** — SVG-based rotating mandala decorations
- ✨ **Champagne Petal Particles** — Floating particle effects across the screen
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- 📍 **Google Maps Integration** — Direct link to the wedding venue
- 🔁 **Replay Ceremony** — Watch the entire animation sequence again
- 🎨 **Royal Dark Theme** — Deep navy background with champagne gold accents

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/abhishekdev-ap/Weding-video-animation-website.git

# Navigate to the project
cd Weding-video-animation-website

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at **http://localhost:3000**

### Build for Production

```bash
npm run build
npm run preview
```
